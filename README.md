# 📊 STK1110 – Momenter, ML‑estimering og Gamma‑fordeling
Dette repoet inneholder arbeidet mitt med Oblig 1 i STK1110 (Høsten 2025). Øvingen fokuserer på sentrale metoder innen statistisk inferens, med særlig vekt på:
- Momentestimering (MoM)
- Maksimum likelihood‑estimering (MLE)
- Gamma‑fordelingen som modell
- Numerisk optimering i R
- Bootstrapping av standardfeil og konfidensintervaller
- Simulering av normalfordelte og t‑fordelte datasett
- Konfidensintervaller for forventning og varians
